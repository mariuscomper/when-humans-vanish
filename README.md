# When Humans Vanish · Când oamenii dispar

A scroll-driven story about what happens to Earth after every human disappears, from the first hour to a billion years. Bilingual (English / Romanian), no build step, no framework.

## Chapters

| # | Chapter | Time | What you see |
|---|---------|------|--------------|
| — | Hero / The moment | now → 10 h | Night globe with lights of 5,479 cities and live flights that run out of fuel |
| I | The lights go out | 1 h → 4 days | 16,679 real power plants (WRI database) dropping off the grid; hover and toggle fuels |
| II | Water in the tunnels | 10 h → 20 yrs | New York subway cross-section flooding once the 753 pumps stop |
| III | The animals notice | weeks | Natural-history specimen labels, filterable (thrives / adapts / vanishes) |
| IV | The cooling pools | days → 1 yr | Nuclear sites on backup diesel, boiling pools, plumes; Cernavodă and Chernobyl |
| V | The sky clears | weeks → 1 yr | Skyglow fades and the Milky Way returns; Bortle-scale slider |
| VI | The forest moves in | 1 → 1,000 yrs | Procedural city that rusts, burns, collapses and turns into forest |
| VII | Closer to home | 5 → 400 yrs | Romania: Carpathians, Transfăgărășan, Danube Delta, Iron Gates, Bărăgan, Bucharest, Chernobyl |
| VIII | What lasts | 1 → 1B yrs | Interactive longevity chart of 19 human-made things |
| IX | The air remembers | 1 → 1M yrs | CO₂ decay curve against the natural 800,000-year range |
| X | Stone and ice | 10k → 1M yrs | Ice-age globe burying northern cities; Bucharest spared |
| XI | A line in the rock | 1M → 100M yrs | Zoom into a future cliff to find our few-centimetre layer and its technofossils |
| XII | The last message | 1B yrs | Voyager and the golden record |

A deep-time gauge (left on desktop, bottom on mobile) tracks the elapsed time on a log scale, and every scene is driven by it.

## Language

English is written in `index.html`; Romanian lives in `js/i18n.js`. `ro/index.html` is **generated** from the two, so `/ro/` is a real Romanian page with its own `lang`, canonical and `hreflang`:

```sh
node tools/build-ro.js   # run after editing index.html or js/i18n.js
```

Both pages can switch language in place (the URL follows: `/` ⇄ `/ro/`). On the English address the page also honours the reader's last choice, then the browser language; `/ro/` always opens in Romanian.

## How the page handles certainty

Facts are stated plainly; estimates carry a range (`10–50 years`) or `~`; modelled futures carry a **scenario** tag. Key claims link to numbered sources in the footer. The maps and animations illustrate the estimates rather than measure them, and their captions say so.

Everything a reader needs is in the HTML: without JavaScript the full story, the specimen cards and the longevity table still render. The canvases are decorative (`aria-hidden`) and each has a text description for screen readers.

## Run locally

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

It must be served over HTTP (the data files are loaded with `fetch`).

## Deploy to mariuscomper.uk

It's a static site: upload the whole folder as-is (`index.html`, `css/`, `js/`, `data/`, `vendor/`, `favicon.svg`, `og.png`).

- **GitHub Pages:** Settings → Pages → deploy from branch, root folder. For the apex domain add a `CNAME` file containing `mariuscomper.uk` and point the DNS A records at GitHub Pages.
- **Netlify / Cloudflare Pages / Vercel:** no build command, publish directory `/`.
- If it lives at a sub-path (e.g. `mariuscomper.uk/vanish/`) nothing needs changing, all paths are relative.
- The canonical, `hreflang`, Open Graph and `sitemap.xml` URLs assume `https://mariuscomper.uk/when-humans-vanish/`. Change them in `index.html` (and re-run `tools/build-ro.js`) if it moves.

## Data

`data/` is generated by `tools/build-data.py` and `tools/build-region.js` from:

- WRI Global Power Plant Database v1.3 (plants ≥ 20 MW)
- Natural Earth 10m populated places (cities ≥ 20,000 people) and rivers
- world-atlas@2 (land 110m, countries 50m)

Libraries in `vendor/`: d3-array, d3-geo, topojson-client (ISC licence).

Sources for the facts are listed in the page footer.
